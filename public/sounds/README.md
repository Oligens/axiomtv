# Ambiance AgwèStream

Déposez ici `ocean-waves.mp3` pour utiliser un véritable enregistrement de vagues.

Le composant `AmbientOcean` tente d'abord `/sounds/ocean-waves.mp3`. Si le fichier est absent ou si l'autoplay est refusé, il utilise automatiquement une texture océanique générée avec Web Audio après le premier geste utilisateur.

Recommandations : MP3 stéréo, 44.1 kHz, boucle sans coupure perceptible, niveau normalisé modéré. Le volume applicatif est volontairement limité pour rester une ambiance et non un contenu principal.
